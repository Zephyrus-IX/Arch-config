# Arch + Hyprland Config

A personal Arch Linux + Hyprland setup

##
### What this is and who its for:
This is my personal Arch linux + Hyprland configuration/setup. All the files within this repo are designed and structured in a way that works best for me. I try to follow some conventions, but primarily things are layed out in a way thats easy for me.

I have done my best to make this setup something that can be easily installed on other peoples devices, not just my own. However, I cannot currently guarentee that it is flawless. I have included a detailed guide to how I expect a new install to be done. I you are looking for a flawless setup that you can just install, this is not for you, but if you are looking for a decent starting point or inspiration you may find this helpful. 

Once again this is my PERSONAL setup as such it will likely continue to change and get better with time. (I am new at the whole ricing and linux customization scene) I am however, very open to reccomendations and suggestions!
